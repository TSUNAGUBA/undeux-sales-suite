# アパレル在庫健全性の業務知識

小売から週次で提供される売上参照データを用いるメーカー側の在庫管理では、滞留・不動の在庫をいかに早く見つけ、発注抑制・値下げ・売場再点検の判断につなげるかが重要になる。そのため在庫の状態を「健全・注意・滞留・不動」の業務語彙に分類し、推奨アクションへ接続する。

## 状態の業務定義

| 状態 | 業務上の意味 | 判定の考え方 | 想定対応 |
|---|---|---|---|
| 健全 | 在庫日数・出荷ペースとも問題なし | 下記いずれにも該当しない（在庫ゼロ＝売り切り済みを含む） | 対応不要 |
| 注意 | 在庫日数が長め。滞留の予備軍 | 在庫日数が注意閾値（45日）超 | 経過観察（翌週取込後に再確認） |
| 滞留 | 売れ行きに対して在庫が積み上がっている | 在庫日数が滞留閾値（60日）超かつ消化率が上限（75%）未満 | 発注残があれば発注抑制を最優先。なければ値下げ候補 |
| 不動 | 出荷が止まっている在庫 | 直近8週連続で出荷（売上数量）ゼロかつ在庫あり | 経過週数に応じ、売場再点検→値下げ候補→処分の検討 |

- 判定は最新取込週スナップショット（週×小売×SKU粒度）基準。滞留と不動が同時成立する場合は不動を優先する。
- 経過バケット：滞留は在庫日数60〜90／90〜120／120日超、不動は出荷ゼロ8〜12／12〜16／16週以上（16週以上は処分・値引き販売の判断対象）。

## 推奨アクションの語彙（5つに限定）

| コード | ラベル | 適用条件の考え方 |
|---|---|---|
| reduce-order | 発注抑制の検討 | 滞留・不動なのに発注残がある |
| markdown-candidate | 値下げ候補 | 滞留（発注残なし）、または不動12週以上 |
| review-shelf | 売場・棚割の再点検 | 不動化の初期（8〜11週） |
| clearance | 処分・値引き販売の検討 | 不動16週以上の長期化 |
| observe | 経過観察 | 注意状態。翌週取込後に再確認 |

閾値（45日／60日／75%／8週）は初期値であり、実装閾値のSoT（Source of Truth）はコード（`backend/src/UndeuxSales.Core/InventoryHealthRules.cs`）。閾値を変更する場合はコード側のみを変更し、APIレスポンス経由で画面表示に反映される。
