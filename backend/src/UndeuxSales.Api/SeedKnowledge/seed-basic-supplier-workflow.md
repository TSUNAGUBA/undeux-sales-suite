# サプライヤー取引業務の基礎（受発注から支払まで）

しまむらグループとのサプライヤー取引は、おおむね「商談→発注→出荷・納品→検収→請求・支払→売上参照」の流れで進む。

## 取引の全体フロー

1. **商談**：原則毎週火曜日の完全アポイント制。商談確定後、速やかに「アイテム情報」をSORSシステムで登録する。
2. **発注**：アイテム情報の承認後、Web-EDIを通じて「先付発注書」が発行され、この発行をもって契約成立となる。納期の1ヶ月前にWeb-EDIで「一括納品書」（発注書）が発行される。発注の種類には自動発注・売発注（定番商品の週次自動発注）・客注発注があり、発注データはWeb-EDI上でA伝票・C伝票等の伝票として受注する（FAX発注の場合はFAX用紙が一括納品書を兼ねる）。
3. **出荷・納品**：出荷準備（店別数量の確認、値札発行、荷物ラベル・出荷明細書の作成）を行い、「一括納品書」で指定された納期日（商品センター着日）を厳守して納品する。納品経路は商品センター経由が基本で、輸入商品ではセンターを経由せず店舗へ直送する「直流」の仕組みもある。
4. **検収**：毎月20日の店舗検収をもって締め切られる。過不足等はWeb-EDIの「検収相違伝票」で確認する。
5. **請求・支払**：請求データの送受信はなく、検収済伝票から相殺伝票・返品伝票を加減算した金額が翌月20日に指定口座へ振り込まれる（運行協力金1.8%等は相殺）。「支払明細書」「支払伝票一覧表」はWeb-EDIから入手して確認する。
6. **売上参照**：販売実績はWeb-EDIの売上参照データとして提供され、在庫・販売分析に活用できる。

## Web-EDIの位置づけ

Web-EDIは受発注・出荷・請求・支払確認・各種ドキュメント入手までを担う取引の基盤システム。ブラウザ版のみで完結する運用と、ファイル転送型（クライアントシステム）による自社システム連携の両方が提供される。

## サプライヤーの主な義務

- 指定の値札を商品に取り付けて納品する（値札取付編の基準に従う）
- 品質規定・検査基準の遵守（PB商品は生産工場認定・事前検査等の対象）
- 商品画像の登録（先付発注登録後、センター納品日前日までに画像管理システムへ登録）
- 各種遵守宣言書（CoC・商品提案規範・有害物質不使用）の毎年の提出
