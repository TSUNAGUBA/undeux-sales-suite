# 業態「しまむら」の概要と部門構成

業態コード：01

「ファッションセンターしまむら」は、しまむらグループの中核業態。婦人衣料を中心に、紳士・子供衣料、肌着、靴下、靴、バッグ・服飾雑貨、インテリア・寝具まで幅広く扱う総合衣料品店である。商談窓口となる商品部は本社2F（商品1部〜4部）と本社3F（商品5部〜7部）に置かれている。
