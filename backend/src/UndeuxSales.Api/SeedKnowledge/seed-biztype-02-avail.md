# 業態「アベイル」の概要と部門構成

業態コード：02

「アベイル（Avail）」は、ヤング層を中心としたメンズ・レディースファッションと服飾雑貨を扱う、しまむらグループのファッション業態。トレンド性のある衣料に加え、シューズ、服飾雑貨、アンダーウエア・ソックス、インテリア・寝具・生活雑貨も取り扱う。商談窓口となる商品部は本社4Fに置かれている。
