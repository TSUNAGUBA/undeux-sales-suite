# 業態「バースデイ」の概要と部門構成

業態コード：04

「バースデイ（Birthday）」は、ベビー・子供用品を専門に扱う、しまむらグループの業態。新生児用品・ベビー・トドラー・ジュニアの衣料に加え、マタニティ用品、大物育児用品、玩具、学用品雑貨、家具・寝具、フード・衛生雑貨まで、子育てに関わる商品を幅広く取り扱う。商談窓口となる商品部は本社3Fに置かれている。
