# 業態「シャンブル」の概要と部門構成

業態コード：05

「シャンブル（Chambre）」は、生活雑貨と婦人服等を扱う、しまむらグループの業態。婦人アウターや靴・バッグ・アクセサリー等の服飾に加え、インテリア・寝具、収納・バス用品、キッチン・ランチ用品、コスメ・文具といった生活まわりの雑貨を幅広く取り扱う。商談窓口となる商品部は本社4Fに置かれている。
