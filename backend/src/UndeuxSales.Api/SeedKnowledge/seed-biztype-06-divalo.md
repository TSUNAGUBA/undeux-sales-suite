# 業態「ディバロ」の概要と部門構成

業態コード：06

「ディバロ（Divalo）」は、シューズを中心にファッション関連商品を扱う、しまむらグループの業態。レディース（ミセス・ヤング）、メンズ、キッズの各シューズと、服飾雑貨、レディースアウターを取り扱う。商談窓口となる事業部は本社3Fに置かれている（他業態のような複数商品部の構成ではなく、単一の事業部が全部門を担当する）。
