# しまむらグループの概要と取引の基本

## 取引の基本理念

しまむらグループは、サプライヤーとの取引にあたり「公正・適正・合理性」を基本として「お取引の基準」を定めている。取引は公正・妥当を基本に長期の協力を前提とし、双方の繁栄を期待するものとされる。経営理念は「商業を通じ消費生活と生活文化の向上に貢献する」「常に最先端の商業・流通技術の運用によって高い生産性と適正な企業業績を維持する」「世界的視野と人間尊重の経営を基本とし、普遍的な信用・信頼性をもつ誠実な企業運営を続ける」の3点。社員・会社への歳暮・中元を含む一切の贈答、飲食等のもてなしは固く断られており、違反時は取引中断の対象となる。
