アイコンの管理と運用

１．基本的考え方
 アイコンは、商品の価値をお客様へ分かり易く伝える為に、その商品の特長や機能を簡単な絵柄で記号化して
表現します。
しまむらグループでは、統一したアイコンを使用する事で、商品特長の分 かり易さと統一感、ブランドイメージ
の向上に繋げます。
また、アイコンの機能性の基準を定め、お客様に安心してお買い求め頂けるようにします。

２．アイコンの種類
 １）アイコン
 付加価値のついた商品に使用します。
①機能性アイコン………冷温感性、消臭性、はっ水性などの、 しまむら品質基準をクリアした機能商品に使用。
 ② アピールアイコン……綿 100％使用、ストレッチ仕様、本革などの、アピールポイントを表現する商品に使用。

４．アイコンの管理
 アイコンの図案や表記方法・管理は販売企画部が行い、機能性の表現方法の確認は商品管理部が担当します。
アイコンの新規作成、変更、削除は、下記のフローに従います。
商品部 商品管理部 販売企画部

１）手順
 ①商品部は、資材や販促物に新規にアイコンを記載する際は、販売企画部へ申請（新規・変更・削除）します。
 ａ．新規の場合は、資材メーカー等に商品部がデザインを依頼します。
 ｂ．商品部は、販売企画部に申請書を提出します。
 ｃ．既存のアイコンを使用する場合はアイコン一覧表の中から選択し申請は不要です。
 ｄ．既存アイコンを使用する場合、デザイン・カラーは変更しません。
 ②販売企画部は、申請書（新規・変更・削除）の内容を確認します。
ａ．用途、デザイン性の他、既存アイコンとの重複等を確認します。
ｂ．機能性アイコンは、販売企画部長が上記ａで問題がないと判断した場合、商品管理部に申請書を提出
します。
 ｃ．問題がある場合は、申請書を商品部へ差し戻します。

③商品管理部は、デザインと機能性（判定基準）との紐づけを確認します。
ａ．デザインが法律に抵触しないか、付記用語に問題がないか等を確認します。
ｂ．商品管理部長が上記ａで問題がないと判断した場合、販売企画部に申請書を提出します。
ｃ．問題がある場合は、申請書を商品部へ差し戻します。
 ④ 販売企画部は、承認したアイコンを商品部へ連絡します。
 ⑤ 商品部は、承認されたアイコンを資材メーカーやサプライヤーに連絡し資材のサンプルの手配を進めます。
 ⑥ 商品部は資材メーカーやサプライヤーが制作した資材サンプルを販売企画部へ提出します。
 ⑦ 販売企画部は資材サンプルが申請書と相違がないか確認し、相違が無ければ商品部へ連絡します。
⑧販売企画部は申請書を保管し管理します。
 ⑨ 新規申請されたアイコンは販売企画部がマニュアルに追加し更新を行います。

２）PB 商品以外に使用する際は、必要時アイコンの機能性の判定を商品管理部に依頼します。

３）アイコンの優先順位は下記に従い記載します。
①優先順位が同じ場合は、強調したいアイコンを左から記載します。
②商品特長をアピールする目的で、優先順位と異なる順番で記載する場合は、 商品部担当執行役員の承認を得ます。
