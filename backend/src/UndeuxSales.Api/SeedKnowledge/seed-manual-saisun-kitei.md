採寸規定

１．基本的考え方
しまむらグループとサプライヤーは、お客様が安心して商品を購入し、満足してお使い頂くために、企画商品
の寸法用語と採寸方法を統一します。
貿易部とサプライヤーは、 しまむらグループで販売する商品の企画寸法を商品部、EC 事業部、商品管理部に提
示する際は、この採寸規程に従います。

２．運用方法
１）適用範囲
 しまむらグループが取り扱う商品について適用します。
記載の無いアイテムや特別なデザインはこの基準を準用し、一般的な部位を商品に合わせ採寸します。

２）採寸方法
商品企画段階で計測するパターンや型紙の寸法ではありません。 製品を採寸します。
①衣類は、平面に置いた状態で測ります。
②雑貨類は、自然に置いた状態で測ります。
③ヒップやまた下の計測位置が明確で無いものは、仕様書にその位置を判る様に記載します。
例：ヒップ………上辺からの位置寸法を記載

 ３）使用方法
 ①商品検査
 ａ．仕様書のクオリティチェック欄の寸法を確認します。
ｂ．必要に応じて、伸び寸法を記載します。
ｃ．指定部位以外の寸法を記載する場合は、計測部位が判る様に記載します。
ｄ．お客様からのお問い合わせ、トラブル発生時に指定部位以外の企画寸法の指示を依頼する場合があります。
②販売促進
ａ．商品部、EC 運営部、他関連部署に寸法詳細の提出を求められた際に使用します。
ｂ．指定の方法で、寸法を記載し提出します。
ｃ．打出し方法の合わせ、指定部位以外の企画寸法も掲示を依頼する場合があります。
