４．サプライヤーへのお願い
１）正しい出荷可能数/出荷可能日の登録
毎週金曜日18時迄に正しい出荷可能数/出荷可能日の登録
をお願いします。
登録漏れや数量誤り・日付誤りがあると発注が上がらなく
なります。
２）出荷可能数の活用
スタート時は、バイヤーが従来通り出荷可能数を確認して
発注を行いますが徐々に新発注システムで発注数を制御
するようになります。
その為の“第一歩”の為、ご協力お願いします。
