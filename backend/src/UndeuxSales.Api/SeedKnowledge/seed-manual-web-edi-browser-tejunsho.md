１．基本的考え方
この手順書は、しまむらグループが提供する Web-EDI ブラウザ版のみを使用する場合の操作概要です。
この手順書に記載されている以外の操作・詳細については、 Web-EDI の「お取引の基準ドキュメント」から
必要資料・モジュールをダウンロードしてご利用下さ い。

２．受注から出荷までの流れ

１）伝票受注
① TOP メニューで「新規受注件数」を確認します。
 ② 確認 ボタンを押し、伝票を受注します。
２）出荷
 ①商品別数量リスト出力メニューで、リストを出力します。
 受注数に対して商品の実 在庫を確認します。
②店別数量データ出力メニューで、データ（ CSV）を出力します。
 概算の荷物量（センター・店毎の発注数）を受注した段階で把握します。
③没伝登録メニューで、出荷できない伝票の選択と更新を行います。
 ④在庫引当範囲指定メニューで、当日に出荷する商品を選択・確定します。
 ⑤数量確定メニューで受注数に対して、訂正後数量を入力し、確定します。
 ⑥ピッキングリスト出力メニューで、当日出荷する商品のリストを作成します。
 ⑦持込センター納品前日の 12：00 までに出荷登録メニューで「納品予定日 、納品区分（持込、集荷、
直流）、持込センター、識別（任意半角英数字 5 文字）、箱数」を入力し出荷登録します。
⑧持込センター納品前日の 19：00 までに出荷確定し、出荷明細書を作成します。
荷物ラベルは、作成する在庫引当番号の ラ を押下し、必要枚数を入力し、CSV
データを作成します。
