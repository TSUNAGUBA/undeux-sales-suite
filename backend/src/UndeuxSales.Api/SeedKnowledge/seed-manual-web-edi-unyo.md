Web-EDI の運用

１．基本的考え方
 このマニュアルは、当社が無償で提供する Web-EDI の運用を定めています。
 お取引に関わるシステムの為、当社の 社員及びサプライヤー様が理解を深め、運用することで、お取引を円滑に
 進めることを目的とします。

２．開設
 １）登録フロー
 ①口座開設
 C.Byr → 経理部
 ②サプライヤーコード取得
 経理部 → C.Byr
 ③Web-EDI 登録申請書受渡し
 C.Byr → サプライヤー様

 ④Web-EDI 登録申請
 C.Byr → システム 2 部
 ⑤Web-EDI アカウント発行
 システム 2 部 → サプライヤー様
 ⑥Web-EDI 本稼働申請

 ヤー様へ渡します。

 ｂ．サプライヤー様が「 Web-EDI ユーザー登録申請用紙」を作成します。
 ｃ． C.Byr がシステム 2 部へ「 Web-EDI ユーザー登録申請用紙」を提出します。
 ② Web-EDI アカウント発行
 システム 2 部は「 Web-EDI ユーザー登録申請用紙」を受領後、サプライヤー様へ 7 日間以内にメールにて

 ③ Web-EDI 本稼働
 ａ．サプライヤー様の作業担当者が該当 Web-EDI の運用テストを行います。
