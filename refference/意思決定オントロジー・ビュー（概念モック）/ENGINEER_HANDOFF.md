# ENGINEER HANDOFF — UndeuxSales に「意思決定」ビューを追加

> **担当エンジニア（Claude Code）向けの実装依頼書。**
> 完成イメージ・挙動・ダミーデータの正は、**同梱の `index.html`（動く概念モック）**。まずブラウザで開いて挙動を確認してから着手してください。
> このHTMLは**参照実装**です。**CSSやマークアップを移植するのではなく、UndeuxSales の既存デザイン／コンポーネントで同じ挙動を再現**してください。

## 1. ゴール（この挙動が伝わればよい・ピクセル模写不要）

意思決定支援の「オントロジー3次元（意味／関連／アクション＆制約）」を、1オブジェクト（在庫SKU）で見せる。狙いは一本の流れ：

**オブジェクトの3次元を表示 → ③アクション＆制約の「✗」で打ち手が潰れて見える → 制約を通った ○/△ の打ち手だけが「意思決定選択肢カード」へ昇格する**

いちばんの肝は、**③で「追加発注 ✗ MOQ500・LT6週」がグレーアウト＋取消線で"潰れて見える"**こと。制約次元が無ければ選択肢は絵に描いた餅、有れば"実行可能な選択肢"になる、が体感できれば成功。

## 2. 配置

- **「探索・予測分析」の5番目のタブとして追加**：`クロス集計 / ランキング分析 / 散布図・回帰分析 / 重回帰シミュレーター / 【意思決定】` ← 重回帰シミュレーターの右。
- ルートは既存規約に合わせる（例：`/mart/decision`）。
- **メーカー／小売トグルは新設しない**。画面右上の**アプリ共通トグルの状態を読む**だけにする（このビューはその状態で目的関数・打ち手・選択肢を切り替える）。

## 3. 実装スコープ（作りすぎ防止・ここ重要）

**やる**
- 上記の3次元ビュー＋選択肢カードへの昇格の挙動を、UndeuxSales の既存UIコンポーネント（タブ・カード・ピル・トグル）で再現。
- 共通トグル（メーカー／小売）で内容を切替。

**やらない（今フェーズ対象外）**
- 実データ接続は不要。**ダミーデータ固定でOK**（同梱HTMLの `DATA` / `LINKS` 定数をそのまま流用可）。
- 実行処理は作らない。**[判断＆実行] ボタンは飾り**（押したらトースト「実行は次フェーズ」だけ）。
- ②関連の各リンクは、クリックでミニ情報を出すだけ（実遷移不要）。

## 4. 挙動仕様

1. **① 意味**：オブジェクトの属性・状態を表示（品番/季節/原価/売価/粗利率/消化率/在庫日数/状態）。
2. **② 関連**：繋がるオブジェクトを列挙（ブランド/同シリーズ/サプライヤー/販売店舗/代替SKU/上位カテゴリ）。クリックでミニ情報（例：サプライヤー→「MOQ500・LT6週・契約最低取引残」＝③制約の出所）。
3. **③ アクション＆制約**：打ち手ごとに判定ピル（○緑／△橙／✗赤）＋制約理由。**✗はグレーアウト＋取消線**。○/△には「→ 選択肢 A/B/C」タグ。
4. **収束**：③の ○/△ 打ち手**だけ**が下の選択肢カードへ繋がる（矢印/タグで視覚接続。✗は繋がらない）。
5. **選択肢カード A/B/C**：各カードに 予測影響（ダミー数値）／根拠（どの次元から）／AI推奨（★・枠強調）／[判断＆実行]（飾り）。
6. **共通トグル**でメーカー／小売を切替 → 目的関数ラベル・③打ち手・選択肢A/B/C を丸ごと差し替え（2セットとも同梱HTMLにある）。

## 5. ダミーデータ

同梱 `index.html` の `LINKS`（②関連）と `DATA.retail` / `DATA.maker`（③＋選択肢、目的関数）を**そのまま流用**してよい。主役オブジェクトは滞留SKU「HE8800」（消化率52.1%・在庫日数122日・在庫¥21.1M）。
※ UndeuxSales はしまむらグループ文脈（業態：しまむら/アベイル/思夢樂/バースデイ/シャンブル/ディバロ）。SKU例はダミーなのでそのままでOK。業態に合わせた文言微調整は任意。

## 6. ⚠ 相談事項（コーディングで勝手に決めない）

**「アクション＆制約」の"制約ルール"（どのSKUで何がMOQ/LT/予算/棚割/契約で潰れるか）は現場知識が要る設計事項**であり、コーディングタスクではありません。**今フェーズは同梱ダミーで固定**。制約ルールの実体化は次フェーズで瀬戸と一緒に定義します。ここを作り込まない／飾りと誤解しない、の両方を守ってください。

## 7. 受け入れ基準（この4点で合格）

1. ✗制約（追加発注 / 増産）で打ち手が**視覚的に潰れて見える**（グレー＋取消線）。
2. 共通の**メーカー／小売トグル**で目的関数・打ち手・選択肢A/B/Cが**別内容に切り替わる**。
3. ③の ○/△ 打ち手**だけ**が選択肢カードへ**繋がって見える**（✗は繋がらない）。
4. UndeuxSales の既存デザインに馴染む（浮かない）／ダミーのみ／実行処理なし。
